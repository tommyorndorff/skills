# skills

Personal collection of Claude skills and agents.

## Layout

```
skills/   # one directory per skill, each with a SKILL.md
agents/   # one markdown file per agent (subagent definitions)
```

## Skills

| Skill | Description |

## Adding a skill

1. Create `skills/<name>/SKILL.md` with `name` and `description` frontmatter.
2. Put supporting material in `skills/<name>/references/` (or `scripts/`).
3. Add a row to the table above.
